📊 Análise de Repasses do Terceiro Setor

📌 Sobre o projeto

Projeto acadêmico desenvolvido na Fatec Cotia com o objetivo de analisar dados relacionados aos repasses de recursos para o Terceiro Setor no Estado de São Paulo.

O projeto utiliza dados históricos para identificar padrões de distribuição dos recursos, evolução dos gastos e diferenças entre unidades e localidades.

🎯 Objetivo

Desenvolver um dashboard interativo capaz de transformar dados de repasses e gastos em informações visuais que facilitem a análise e a tomada de decisões.

🛠️ Tecnologias utilizadas

* Power BI
* Tratamento e análise de dados
* Visualização de dados
* Dashboard interativo

📊 Principais análises

O dashboard apresenta:

* Valor total dos gastos;
* Evolução dos gastos ao longo dos anos;
* Comparação entre secretarias e unidades;
* Participação dos gastos por unidade;
* Distribuição geográfica dos repasses;
* Comparação entre repasses estaduais e municipais;
* Indicadores e gráficos para análise dos dados.
